# download that does not match. Rows are pipe-separated:
#
#   latest|<version>
#   asset|<version>|<target>|<filename>|<sha256>|<url>
#
# Multiple url columns may follow the first; they are tried in order. The
# hash pinned here decides acceptance, not whichever mirror served the
# bytes. From 3.0.0-rc.7 on, rows are recorded from ngit's signed NIP-82
# release asset events: the hash is the event's sha256, the first URL is
# the content-addressed Blossom URL from the event, and the GitHub
# Releases URL is a trailing fallback mirror. Rows for earlier versions
# were recorded by hashing assets fetched from GitHub Releases, so they
# attest "same bytes as when pinned" without an independent origin.
